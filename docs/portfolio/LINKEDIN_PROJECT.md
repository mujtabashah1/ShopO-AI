# LinkedIn project details

**Project name:** ShopO-AI

**Repository:** https://github.com/mujtabashah1/ShopO-AI

**Description:** Final Year Project built with React, Express, MongoDB, and FastAPI. ShopO-AI searches several shopping sites, compares listings, analyzes review text, and saves a factor-by-factor product risk score. The score is based on rules and text-analysis methods and is not presented as proof of authenticity.

**Skills:** React, Node.js, Express, MongoDB, Python, FastAPI, Puppeteer, REST APIs, Server-Sent Events, JWT, sentiment analysis, TF-IDF, GitHub Actions
