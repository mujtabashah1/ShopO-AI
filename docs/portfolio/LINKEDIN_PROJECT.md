# LinkedIn project entry

**Title:** ShopO-AI — Price Intelligence & Explainable Product Trust Analysis

**Repository:** https://github.com/mujtabashah1/ShopO-AI

**Description:** Built a MERN and FastAPI shopping-intelligence platform that streams multi-marketplace listings, compares prices, analyzes review sentiment and similarity, and stores explainable product-risk recommendations. Designed the analysis boundary carefully: the score combines transparent rules and classical NLP signals and is presented as decision support rather than validated counterfeit detection.

**Skills:** React.js, Node.js, Express.js, MongoDB, Python, FastAPI, REST APIs, Server-Sent Events, Web Scraping, Puppeteer, Natural Language Processing, VADER, TextBlob, TF-IDF, JWT Authentication, GitHub Actions
